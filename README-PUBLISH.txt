MINLU GLOBAL TRADE WEBSITE PACKAGE

Contents:
- index.html: bilingual responsive homepage (English default, Chinese toggle)
- assets/: selected and optimized product and factory photographs

Publish to the existing GitHub Pages repository:
1. Open https://github.com/sarahwu3223/GLOBAL-TRADE-EMPIRE
2. Open the repository's main branch.
3. Upload the complete contents of this folder, including the assets folder.
4. Replace the existing index.html when prompted, and add the assets folder and all its images.
5. Commit the changes to the main branch.
6. Wait for GitHub Pages to rebuild, then refresh the live website.

Notes:
- Product photos are grouped into separate Tactical Storage Bag and Apple Watch Ultra Protective Case sections.
- Factory photos are displayed in a separate Manufacturing section.
- The watch is not included; only the protective case is shown.
- Confirm exact watch compatibility and any test/performance claims before accepting orders.
